・SSBOとかIndirect Argのメモリバリアはいる
・深度値の範囲

・SceneManager で使う，DescPool，FrameRenderDataとか，引数でその都度，外から渡そう．
	・Scene.CommitRenderResources() でDescPoolの更新はしなくなる（外部から渡すから），Modelの削除とかだけやる
	・Scene 以外でBindするもののために，RenderQueue，HizとかはFrameRenderDataに別枠の部分を設ける．
・CommandBufferも同様に，中で配列はやめて，外で，CommandBuffer[2] として持つ．
・スカラーレジスタを使えばいいので，Clusterはシェアードに入れたほうがむしろ遅い
・TileIndexは16bitでいい， sizeof(uin16_t)*tile_num*MAX_MATERIAL
・GLSLのTexutreには，Float16Vec2をそのまま渡せるらしい
・ModelはRender::PrimitiveDataをやめて，普通にcbfa::PrimitiveDataを持つ．

・比較
	・zpre + vertex + forward
	・2pass hiz + mesh + forward （と思ったが，描画単位をClusterに分解したせいで，FSを差し替えるのはむずそうなのでなし）
	・2pass hiz + mesh + visiblity
	・2pass hiz + mesh + HWSW_Raster + visiblity 
	  (SW_Rasterの面積見積もりは，Bounding Sphere と Normal Cone で出す，AABBは重いかも)
	・2pass hiz + mesh + normal cone + frustum + contirbution
	・2pass hiz + mesh + soft triangle culling 

・TextureTable，MaterialTableとかは毎フレーム全部作り直す（非同期のフェーズで）

・あと，ModelData(頂点バッファとか，テクスチャとか)の破棄のタイミングも
  DescPoolのUpdate と同様に，Renderingが終わってからやるように．
  Rendering 中に破棄されたらまずい
  （Uniqueになってるはずだから，破棄予定のVectorに詰めて，Resize(0)でOK）
